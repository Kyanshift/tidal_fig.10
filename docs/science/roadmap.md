# 科研路线与参数敏感性

用户确认：Windows + Python 3.12；正式版 Brahm 为基准；允许 REBOUND + REBOUNDx，保留 Jackson 方程参考实现；当前初始化不实现物理求解。

## 阶段一：Fig.10 的可验证基准

先按 `fig10_reproduction.md` 确定模型对应并建立中心曲线。将数值容差/采样频率与物理因素分开，不把数值误差当作 Q′ 效应。正式论文报告值不变；第一条名义曲线优先使用单独保存的历史有效分母配置，正文数值另作对照。见 `tidal_quality_factors.md`。

## 阶段二：影响因子

必选：**Q′_star 与 Q′_planet**，字段为 `model.tides.q_prime_star`、`model.tides.q_prime_planet`。设计文件：`configs/sweeps/tidal_quality_factors.yaml`。

初步探索采用历史有效分母基准（恒星 10^6、行星 32000）的 0.1/1/10 倍，先单因素再二因素联合扫描。此范围只是项目提出的探索设计，不是文献测量误差或已确定的合理范围。模型映射验证前不发起物理扫描。

单因素共有五组不同设定（共享一个中心基准），全因子九组。采用三个配对种子做小规模试验；相同种子必须对应相同初始样本，之后才能把差异归因于 Q′。先评估单次成本与收敛性，再决定扩大的样本数和计算预算。记录工具不会仅凭种子替模拟器初始化随机数。

正文/历史数值差异、预印本文字及文献定义换算分别作对照，不能当作同一种误差范围。木星约束到本行星的迁移与 Penev 数值的解释仍为假设，换算对照不自动替代原图输入。

随后研究恒星半径固定/演化、观测初态采样及采样协方差。比较 e(t)、a(t)、最小近日点/Roche 比、吞没/破坏时间及终止原因；没有发生事件的实验记录为未发生/右删失，不能把积分结束时间当事件时间。

## 阶段三：形成与初始架构

问题：哪些初始架构、额外行星扰动和盘迁移历史能产生与观测一致的现今系统？参数入口涵盖初始 a/e、伴星质量和轨道、互倾角、迁移与 e 阻尼、盘消散时间。范围尚待物理先验与试验约束，配置中保留 null，不制造假定伴星观测。

盘阶段和盘后阶段应有明确的时间交接、状态保存和力模型；向前搜索检验可能的形成路径。反向耗散积分可以作模型条件下的历史轨迹推断，但不能恢复随机散射历史的唯一真实初态。

结果应报告可行架构族及退化性；能匹配现今 a/e 不等于唯一确定在盘中的形成半径。将模型先验、当前观测约束和未检验的化学/形成信息分别说明。
